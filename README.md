# Sahil's Homebrew Tap

A [Homebrew](https://brew.sh) tap for my command-line tools.

```bash
brew install Sahilll15/tap/netdoctor
brew install Sahilll15/tap/lazygocd
```

(or `brew tap Sahilll15/tap` once, then `brew install netdoctor`)

## Formulae

| Formula | Description |
|---|---|
| **lazygocd** | A fast, keyboard-driven terminal UI for GoCD pipelines. → [repo](https://github.com/Sahilll15/lazygocd) |
| **netdoctor** | A network health-check CLI that walks the DevOps debugging ladder (DNS → TCP → HTTP/TLS) and grades each host A+→F. → [repo](https://github.com/Sahilll15/netdoctor) |

---

Formula checksums are updated automatically on each release of the upstream tool.
